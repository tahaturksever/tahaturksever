## Hakkımda

Ben **Taha Türksever**, **Yıldız Teknik Üniversitesi İstatistik Bölümü** son sınıf öğrencisiyim (mezuniyet: Haziran 2027).  
Odak alanlarım **veri analizi, istatistiksel modelleme, finansal piyasalar ve veri odaklı karar sistemleri**.

Veriyi yalnızca raporlamakla değil; onu **eşleştirme motorlarına, alım-satım sinyallerine, portföy kararlarına ve iş süreçlerini hızlandıran otomasyonlara** dönüştürmekle ilgileniyorum.

Fikirden canlı ürüne kadar hızlı ilerlemek için **AI destekli geliştirme** kullanıyorum: metodolojiyi ben tasarlıyor, kodu doğruluyor ve testlerle güvenceye alıyorum.

## Öne Çıkan Projeler

<details>
<summary><b>UpDate — Uyum Testine Dayalı Tanışma Uygulaması</b></summary>

<br/>

**UpDate**, kaydırma yerine yapılandırılmış bir uyum testiyle eşleştiren bir tanışma uygulamasıdır.

| Başlık | Detay |
|---|---|
| Odak | Matching Engine, Statistical Scoring, Product |
| Stack | Next.js, TypeScript, Supabase, Playwright |
| Yöntem | Ağırlıklı güç ortalaması, iki yönlü geometrik ortalama, kesin şart kapıları |
| Gizlilik | Puanlar yalnızca sunucuda hesaplanır, KVKK onay akışları |
| Canlı Ürün | [updateapp.io](https://www.updateapp.io) |
| Repository | Private |

Cevaplar boyut puanlarına çevrilir, konu konu benzerlikler hesaplanır ve iki yön birleştirilir; böylece bir eşleşme iki kişi için de anlamlı olmak zorundadır.

</details>

<details>
<summary><b>Trading Signal Bot — Kural Tabanlı Kripto Futures Sinyal Motoru</b></summary>

<br/>

Takdire dayalı bir range-trading yöntemini, deterministik bir durum makinesine dönüştüren sinyal motorudur.

| Başlık | Detay |
|---|---|
| Odak | Quant Finance, State Machines, Backtesting |
| Stack | Python, pytest, Telegram Bot API, systemd |
| Kapsam | Yüzlerce parite taraması, kural bazlı LONG / SHORT / NO_SIGNAL açıklamaları |
| Doğrulama | Geçmiş veri testleri ve look-ahead kontrolleri |
| Çalışma | VPS üzerinde 7/24, Telegram bildirimleri, emir göndermez |
| Repository | Private |

Her sinyal hangi kuralın neden sağlandığını adım adım açıklar; amaç stratejiyi iyileştirmek değil, ona sadık ve test edilebilir bir uygulama kurmaktır.

</details>

<details>
<summary><b>S&P 500 LLM Portföyü — Sistematik Hisse Portföy Pipeline'ı</b></summary>

<br/>

S&P 500 bileşenlerinin tamamını kapsayan, LLM destekli sistematik portföy yönetim sistemidir.

| Başlık | Detay |
|---|---|
| Odak | Portfolio Management, LLM Pipelines, Data Engineering |
| Stack | Python, yfinance, LLM APIs, Docker, GitHub Actions |
| Ölçek | 503 şirket, haftada 2 çalışma, 8 aşamalı checkpoint'li pipeline |
| Kalite | 400+ test fonksiyonu |
| Çıktı | Telegram üzerinden skor, dağılım ve fiyat seviyesi sinyalleri |
| Repository | Private |

Şu an yalnızca paper trading ile çalışıyor; gerçek getiri iddiası yok, sonuçlar mutabakat adımıyla takip ediliyor.

</details>
