### Projects

**[UpDate](https://www.updateapp.io)**: compatibility-first dating app<br>
Users take a structured compatibility test, and a server-side engine scores every pair: per-topic similarities are combined with a weighted power mean, both directions are merged with a geometric mean, and hard deal-breaker gates filter out incompatible pairs.<br>
*Next.js · TypeScript · Supabase · Playwright*

**Trading Signal Bot**: rule-based crypto futures signal engine<br>
Turns a discretionary range-trading method into a deterministic state machine that prints LONG / SHORT / NO_SIGNAL with a rule-by-rule explanation. Includes historical validation and look-ahead checks, scans hundreds of pairs, and runs 24/7 on a VPS with Telegram alerts. Signal-only: it never places orders.<br>
*Python (standard library) · pytest · Telegram Bot API · systemd*

**S&P 500 LLM Portfolio**: systematic equity portfolio pipeline<br>
LLM-assisted pipeline covering all 503 S&P 500 constituents: automated re-scoring, allocation, price-level generation and paper-trade reconciliation, delivered as Telegram signals twice a week. Built as an 8-stage checkpointed pipeline with Docker, GitHub Actions and 400+ tests. Paper trading only.<br>
*Python · yfinance · LLM APIs · Docker · GitHub Actions*
